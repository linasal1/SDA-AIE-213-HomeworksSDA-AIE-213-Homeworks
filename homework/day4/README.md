# Day 4 — Real Model Evaluation

## Objective
Evaluate three answers generated by a real language model using different versions of the same question.

## Implementation
- Used the `google/flan-t5-small` model on CPU.
- Generated answers for three FAQ paraphrases (E01–E03).
- Recorded input tokens, output tokens, and inference time.
- Calculated a keyword indicator using "reference" and "number".
- Manually evaluated each answer for correctness and unsupported information.

## Results
- **Model:** google/flan-t5-small
- **Total Cases:** 3
- **Keyword Hits:** 3/3 (100%)
- **Total Inference Time:** 0.600 seconds
- **External Inference API Calls:** 0
- **Manual Evaluation:** All three answers were supported by the provided context.

## Key Findings
All three generated answers correctly indicated that a reference number is needed to check an application status.

However, keyword matching alone does not measure semantic accuracy. Manual evaluation is necessary to determine whether generated answers are meaningful and supported by the context.

## Limitations and Improvements
- **Limitation:** Only three similar questions were evaluated, which is insufficient to establish general model accuracy.
- **Improvement:** Expand the test set to include more diverse, ambiguous, and unsupported questions.
