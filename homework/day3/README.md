# Day 3 — Input Validation and Error Handling

## Objective
Practice input validation and exception handling by identifying invalid inputs and correcting them.

## Implementation
- Implemented input validation using Python.
- Used `raise` to trigger errors for invalid inputs.
- Used `try` and `except` to catch expected errors.
- Tested `None`, blank text, and input exceeding 500 characters.
- Verified that a corrected question was accepted.

## Results
- **Invalid Inputs Correctly Rejected:** 3/3
- **Corrected Input:** Accepted
- **Overall Checks:** Passed
- **Unhandled Errors:** None

## Key Concepts
- **raise:** Triggers an exception when a validation rule is violated.
- **try:** Executes code that may raise an exception.
- **except:** Catches an exception and allows the program to handle it.

A caught rejection is considered a successful test when the application correctly identifies and handles invalid input.
